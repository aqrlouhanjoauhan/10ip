隐私权政策 (Privacy Policy)

最后更新时间：2026年10月

「免费VPN Proxy - 赠10个海外独立IP与住宅代理」（以下简称“本扩展”）高度重视用户的个人隐私与数据安全。本隐私政策旨在向您说明本扩展如何处理和保护您的信息。

1. 数据收集声明（零数据收集承诺）

我们承诺绝不收集、记录、传输或分享您的任何个人数据或隐私信息。

  • 我们不收集您的姓名、电子邮箱、手机号等个人身份信息。
  • 我们不记录或监控您的浏览历史、访问网址、搜索关键词或网络活动。
  • 我们不收集或储存您的表单输入、按键记录或敏感账户凭证。

2. 本地存储 (Local Storage) 的使用

为了保证代理工具的正常运行，以下数据仅在您的设备本地浏览器沙盒（chrome.storage.local）中保存：

  • 您自行配置的代理服务器地址与端口；
  • 您所填写的 Webshare API Token 或代理凭证（仅用于本地向代理服务商发起鉴权与获取节点列表）；
  • 当前的代理开关状态与选中的节点记录。

上述所有配置数据均保留在您的本地设备中，绝不会上传至任何第三方服务器或由开发者运营的服务器。

3. 权限使用说明

  • proxy：仅用于根据您选择的节点在本地接管浏览器的网络转发规则。
  • privacy：仅用于启用 disable_non_proxied_udp 策略，阻断 WebRTC 穿透泄漏您的公网真实 IP。
  • webRequest / webRequestAuthProvider：仅用于静默向代理服务器提供您本地配置的代理账号与密码，免除频繁弹窗。
  • storage：仅用于在本地保存您的节点与运行偏好。

4. 第三方服务

当您使用 Webshare 提供的代理服务时，网络流量将经过 Webshare 的代理节点，其数据处理规则受 Webshare 官方隐私政策约束。本扩展本身不设立任何中继服务器或流量拦截代理。

5. 政策变更与联系方式

如本政策有任何更新，将在此页面直接发布。如对本政策有任何疑问，可通过扩展商店支持页面联系我们。
